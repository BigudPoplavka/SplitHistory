# SplitHistory — историко-контекстуальные заметки

Первая рабочая версия десктопного приложения по описанию из «Описание идеи приложения.txt»:
многослойный 3D-редактор знаний с картой, графом связей и временной шкалой.

## Стек и почему так

Node.js/npm в этом окружении не установлены, поэтому собрать и прогнать приложение здесь не
получилось — весь код написан «на бумаге» и проверен только чтением. Ссылка на обоснование
стека из ChatGPT не открылась (страница отдаёт пустой заголовок без содержимого без авторизации),
поэтому решения по стеку приняты самостоятельно, с упором на то, что можно надёжно написать и
проверить без возможности запуска:

- **Electron** — десктоп-оболочка, доступ к файловой системе для хранения `vault.json`.
- **Чистый JS + ES-модули через `<script type="module">` и import map** — без сборщика
  (webpack/vite). Меньше движущихся частей, которые негде было бы протестировать сборкой.
- **three.js** — единственная тяжёлая зависимость, для 3D-сцены слоёв (карта внизу, слои-плоскости
  над ней, заметки-узлы, рёбра связей, подписи через `CSS2DRenderer`, `OrbitControls` для навигации).
- **Свой мини force-layout и своя equirectangular-проекция** вместо d3-force/d3-geo/topojson —
  сознательно, чтобы не тянуть цепочку ESM-пакетов с бинарными данными, которую негде было
  прогнать и проверить на импорт-ошибки. Это ~80 строк кода в `src/layout.js` и `src/projection.js`.
- **Хранилище — JSON-файл** (`vault.json` в userData) через IPC/`contextBridge`, без БД. Проще всего
  для первой версии; на будущее миграция на SQLite (`better-sqlite3`) не потребует менять модель
  данных, только слой `store.js`.

## Как запустить

Нужен установленный **Node.js 18+** (npm идёт в комплекте) — https://nodejs.org.

```
npm install
npm start
```

При первом запуске приложение скопирует демонстрационное хранилище (`data/vault.sample.json`,
контекст вокруг Исаака Ньютона — событий, людей и идей) в пользовательскую папку и откроет его.

## Что реализовано

- Многослойная 3D-сцена: карта (ground-слой) + слои-плоскости над ней («Люди», «События», «Идеи»),
  заметки как узлы, связи как рёбра, в том числе между разными слоями.
- Заметки с геопривязкой (lat/lng) проецируются на карту; их положение на верхних слоях
  автоматически выравнивается по вертикали через силовой лэйаут связей.
- Заметки без геопривязки собираются в кластер силовым алгоритмом (притяжение по связям,
  отталкивание между узлами).
- Временная шкала (нижняя панель): фильтрация заметок и связей по диапазону лет, включая до н.э.
  (отрицательные годы).
- Левая панель «Хранилище»: дерево заметок, группировка по слоям / типу / веку.
- Правая панель: список слоёв (видимость, добавление, редактирование имени/цвета, удаление),
  сводка по выбранному слою (число заметок, «вес», число связей).
- Мини-граф (нижний левый угол): плоский обзор геопривязанных заметок и связей выбранного слоя
  поверх упрощённого контура континентов.
- Редактор заметки: название, слой, тип, даты, гео, описание, связи с другими заметками (с типом
  связи), удаление.
- Сохранение/открытие хранилища: `Ctrl+S`, `Ctrl+Shift+S`, `Ctrl+O`, а также через меню «Файл».

## Известные упрощения / что дальше

- Контуры континентов на карте — сильно упрощённые многоугольники «на глаз», не географические
  данные. Для точной картографии позже стоит подключить `world-atlas` + `topojson-client` +
  `d3-geo` (в идее приложения это и предполагалось).
- Регионы/маршруты/территории «во времени» (из раздела 2 идеи) не реализованы — только точки.
  Требуют полигональной геопривязки и отдельного рендера на карте.
- Группы/кластеры заметок как единый визуальный узел (как на референс-скриншоте с серыми
  эллипсами) не реализованы — пока каждая заметка отдельный узел.
- Нет ИИ-подсказок, автоизвлечения сущностей, экспорта в Neo4j/Gephi, синхронизации между
  устройствами — см. раздел 8 идеи, сознательно оставлено на потом.
- Раз в этом окружении не было Node.js, **приложение ни разу не запускалось и не тестировалось
  визуально** — после `npm install && npm start` возможны мелкие ошибки (опечатка, путь), которые
  стоит проверить в первую очередь через `Ctrl+Shift+I` (DevTools) и консоль.
