# SplitHistory — историко-контекстуальные заметки

Десктопное приложение по описанию из «Описание идеи приложения.txt»: многослойный 3D-редактор
знаний с картой, графом связей и временной шкалой — для истории, географии и смежных
исследовательских задач (включая link-analysis в OSINT-стиле, см. `docs/research.md`).

## Стек и почему так

- **Electron** — десктоп-оболочка, доступ к файловой системе для хранения `vault.json` и вложений.
- **Чистый JS + ES-модули через `<script type="module">` и import map** — без сборщика
  (webpack/vite). Меньше движущихся частей.
- **three.js** — для 3D-сцены слоёв (карта внизу, слои-плоскости над ней, заметки-узлы, рёбра
  связей, подписи через `CSS2DRenderer`). Камера — фиксированный изометрический ракурс с зумом
  (без свободного вращения — оно ощутимо грузит GPU при постоянном перерендере).
- **Свой мини force-layout и своя equirectangular-проекция** вместо d3-force/d3-geo/topojson —
  сознательно, чтобы не тянуть цепочку ESM-пакетов с бинарными данными. Это `src/layout.js`,
  `src/layout2d.js` и `src/projection.js`.
- **Хранилище — JSON-файл** (`vault.json` в userData) через IPC/`contextBridge`, без БД.
- **vitest** — юнит-тесты для всей чистой логики (`tests/*.test.js`), без Electron/DOM.

## Как запустить

Нужен установленный **Node.js 18+** (npm идёт в комплекте) — https://nodejs.org.

```
npm install
npm start
```

При первом запуске приложение скопирует демонстрационное хранилище (`data/vault.sample.json`,
контекст вокруг Исаака Ньютона — людей, событий, идей и источников) в пользовательскую папку и
откроет его.

## Тестирование

```
npm test
```

Юнит-тесты (vitest) покрывают всю логику без DOM/Electron: модель данных и её инварианты
(`src/store.js`), геометрию и проекции (`src/geo.js`, `src/projection.js`), силовой лэйаут,
поиск, поиск дублей (`src/similarity.js`), экспортёры (`src/export/*.js`) и импорт BibTeX
(`src/import/bibtex.js`). UI-модули (`src/ui/*.js`) тестируются вручную — см. чек-лист ниже.

## Что реализовано

**Визуализация**
- Многослойная 3D-сцена: карта (ground-слой) + слои-плоскости над ней, заметки-узлы, рёбра
  связей (в т.ч. между разными слоями), маршруты и регионы как линии/контуры поверх карты.
  Рендер по требованию (не 60 кадров/сек вхолостую) — фиксированный ракурс, зум колесом.
- 2D-режим отдельного слоя (переключатель 3D/2D слой в углу сцены): граф выбранного слоя поверх
  контурной карты мира, связи только внутри слоя.
- Мини-граф (нижний левый угол в 3D-режиме): обзор геопривязанных заметок выбранного слоя.
- Временная шкала: диапазон от 1000 г. до н.э. до текущего года, масштаб (1000/100/10 лет/весь
  период) и панорамирование отдельно от выбранного диапазона фильтрации; именованные периоды/эпохи
  показываются отдельной плашкой.

**Заметки**
- Каждая заметка открывается как перетаскиваемое, растягиваемое плавающее окно (можно открыть
  несколько одновременно, они сворачиваются в док-панель сверху). Автосохранение при каждом
  изменении поля.
- Markdown-текст без ограничений, ссылки на другие заметки через `[[Название]]` с автодополнением
  по мере набора; связи в граф добавляются автоматически, не удаляя связи, заданные вручную.
- Теги через запятую, группировка дерева заметок по слоям / типу / тегам / веку.
- Нечёткие даты (`ок.`) и именованные периоды с отображением на шкале времени.
- Геопривязка трёх видов: точка, маршрут (ломаная с датами), регион (замкнутый контур).
- Источники: отдельный тип заметки с полями цитирования (автор, год, издание, URL, надёжность
  1–5); индикатор подтверждённости факта источниками в панели слоя и в панели заметки.
- Вложения (любые файлы, копируются в userData) и история изменений (снапшоты title/content,
  восстановление прошлой версии).
- Предупреждение о похожих/дублирующихся заметках того же типа при наборе названия.
- Шаблоны заметок (Личность/Событие/Источник/Артефакт) — кнопка со стрелкой рядом с «+ Заметка».
- Полнотекстовый поиск (название/текст/теги) — фильтрует дерево и видимость в 3D/2D.
- Удаление заметки — через контекстное меню (правый клик по заголовку окна или по строке в
  дереве) или клавишей Delete/Backspace, когда заметка выбрана и фокус не в текстовом поле.

**Данные**
- Сохранение/открытие хранилища: `Ctrl+S`, `Ctrl+Shift+S`, `Ctrl+O`, меню «Файл».
- Экспорт: GraphML (Gephi/yEd), GeoJSON (QGIS/Google Earth), CSV таймлайна (TimelineJS) — меню
  «Файл → Экспорт».
- Импорт источников из BibTeX — меню «Файл → Импорт источников».

## Известные упрощения / что дальше

Актуальный бэклог с приоритетами и планами внедрения — `docs/tools_ideas.md` (инструменты для
истории/географии) и `docs/research.md` (OSINT-функции). Не реализовано сознательно (см. эти
документы): эвристический помощник связей и обогащение из WikiData/OSM — оба требуют более
взвешенного UX (последний — ещё и сетевые вызовы с явным согласием пользователя).

- Контуры континентов на карте — упрощённые многоугольники «на глаз», не географические данные.
- Регионы/маршруты редактируются как список «широта, долгота» по одной паре на строке (текстом,
  не покликово) — сознательное упрощение ради скорости реализации.
- Группы/кластеры заметок как единый визуальный узел (как в раннем референс-скриншоте) не
  реализованы — каждая заметка отдельный узел.
